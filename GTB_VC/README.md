# GreenTea Bot v3.2

Локальный инженерный Telegram-бот на базе **Ollama** и локальной языковой модели.  
Бот рассчитан на работу на слабом железе, использует минимальный внешний каркас, сам создаёт нужные файлы при первом запуске и держит модель в памяти, чтобы первый пользовательский запрос не был медленным.

---

## Особенности

- **Монолитный запуск**: при первом старте бот сам создаёт:
  - `settings.toml`
  - `prompts/GreenTea_v4.txt`
  - папку `logs/`
- **Прогрев модели при старте**: модель загружается заранее, а не только при первом запросе.
- **`keep_alive` по умолчанию 6 часов**: модель дольше остаётся в памяти.
- **Автоматическая проверка и попытка запуска `ollama serve`**.
- **Поддержка прокси**:
  - авто-ротация `socks5`
  - прямой режим
  - ручной прокси
- **Нейтральная замена анонимного админа чата**:
  - по умолчанию используется имя `Админ`
  - можно поменять через `[advanced]`
- **Админ-панель в ЛС**:
  - `/status`
  - `/history`
  - `/clear`
  - `/set`
  - `/reset`
- **Логи в файл и в консоль**.
- **Конфигурация полностью через `settings.toml`**.
- **Служебные настройки вынесены в секцию `[advanced]`**.

---

## Требования

- **Python 3.11+**
- **Ollama**
- Заранее скачанная модель в Ollama
- Желательно локальная машина с достаточным объёмом ОЗУ для выбранной модели

## Установка и подготовка Ollama

Установите Ollama и скачайте модель, например:

```bash
ollama pull qwen2.5-coder:7b-instruct-q4_K_M
```

Проверка:

```bash
ollama list
```

Если вы используете десктопную версию Ollama, сервис обычно уже запущен.  
Если используете консольный вариант, сервер можно запустить так:

```bash
ollama serve
```

Бот при старте сам проверит доступность `http://localhost:11434` и при необходимости попробует запустить `ollama serve`.

## Подготовка бота в Telegram

1. Создайте бота через **@BotFather**.
2. Получите токен.
3. Узнайте нужный `chat_id`.
4. Для работы в группе желательно:
   - либо добавить бота администратором,
   - либо отключить ему **privacy mode** через BotFather:
     - `/setprivacy`
     - выбрать бота
     - выбрать `Disable`

Иначе бот может не видеть обычные сообщения группы, а только команды, ответы и упоминания.

## Первый запуск

Запустите скрипт:

```bash
python GTB_VC.py
```

Если файла `settings.toml` ещё нет, бот:

1. создаст конфигурацию по умолчанию;
2. создаст стандартный промпт `prompts/GreenTea_v4.txt`;
3. попросит заполнить настройки и завершится.

После этого отредактируйте `settings.toml` и запустите бота снова.

## Файл токена

Токен можно хранить двумя способами:

### 1. В `settings.toml`

```toml
[bot]
token = "ВАШ_ТОКЕН"
```

### 2. В отдельном файле `key`

Если `token = ""`, бот прочитает токен из файла `key` рядом со скриптом.

Файл `key` должен содержать только сам токен.

> Не коммитьте `key` или заполненный `settings.toml` с токеном в git.

## Основные настройки: `settings.toml`

При первом запуске создаётся полный шаблон. Ниже описаны основные секции.

---

## Секция `[bot]`

```toml
[bot]
token = ""
chat_id = -1001234567890
username = "MyBot"
owner_id = 123456789
random_reply_chance = 0.05
proxy = ""
```

| Параметр | Описание |
|---|---|
| `token` | Токен бота. Если пустой, берётся из файла `key`. |
| `chat_id` | ID целевого чата, где бот будет отвечать. Для групп обычно отрицательный. |
| `username` | Имя бота без `@`. Используется для распознавания упоминаний. |
| `owner_id` | Ваш личный Telegram ID. Только он получает служебные сообщения и имеет доступ к админ-панели. |
| `random_reply_chance` | Шанс случайного ответа от `0.0` до `1.0`. |
| `proxy` | Режим прокси: `""` или `auto`, `direct` / `none`, либо конкретный `socks5://host:port`. |

---

## Секция `[ollama]`

```toml
[ollama]
model = "qwen2.5-coder:7b-instruct-q4_K_M"
prompt = "GreenTea_v4"
cpu_threads = 0
keep_alive = "6h"
warmup = true
```

| Параметр | Описание |
|---|---|
| `model` | Модель, установленная в Ollama. |
| `prompt` | Имя файла промпта без `.txt`. Например, `GreenTea_v4`. Если указать пустую строку, бот будет работать без системного промпта. |
| `cpu_threads` | Число потоков CPU. `0` — авто. |
| `keep_alive` | Сколько времени держать модель в памяти. Рекомендуется `"6h"`. |
| `warmup` | Прогревать ли модель при старте. |

---

## Секция `[generation]`

```toml
[generation]
temperature = 0.4
top_p = 0.9
repeat_penalty = 1.2
context_window = 8192
max_tokens = 1024
```

| Параметр | Описание |
|---|---|
| `temperature` | Температура генерации. |
| `top_p` | Nucleus sampling. |
| `repeat_penalty` | Штраф за повторы. |
| `context_window` | Контекстное окно в токенах. |
| `max_tokens` | Максимальная длина ответа в токенах. |

---

## Секция `[script]`

```toml
[script]
logs = true
```

| Параметр | Описание |
|---|---|
| `logs` | Включить или выключить запись логов в файл. |

Логи пишутся в папку `logs/`.

## Секция `[advanced]`

Это служебные настройки.  
Меняйте их только если понимаете, что делаете.

При первом запуске бот создаёт полный набор таких параметров со значениями по умолчанию.

Пример:

```toml
[advanced]
max_history_size = 10
chars_per_token = 2
ollama_check_timeout = 8.0
ollama_warmup_timeout = 900.0
restart_delay = 5.0
max_backoff = 300.0
message_limit = 4000
input_limit = 4096
error_text_limit = 500
send_attempts = 3
retry_base_delay = 3.0
greet_cooldown = 60
recovery_greet_cooldown = 10
proxy_cache_ttl = 600
proxy_fetch_timeout = 10
proxy_preflight_timeout = 8
proxy_health_interval = 25
proxy_health_fails = 2
telegram_connect_timeout = 10.0
telegram_read_timeout = 15.0
telegram_pool_timeout = 10.0
anonymous_admin_name = "Админ"
anonymous_admin_username = "@GroupAnonymousBot"
anonymous_admin_user_id = 1087968824
anonymous_admin_aliases = ["админ", "admin", "group", "группа"]
```

### Основные параметры `[advanced]`

| Параметр | Описание |
|---|---|
| `max_history_size` | Сколько последних сообщений держать в истории. |
| `chars_per_token` | Оценка числа символов на один токен. |
| `ollama_check_timeout` | Таймаут проверки доступности Ollama. |
| `ollama_warmup_timeout` | Таймаут прогрева модели при старте. |
| `restart_delay` | Пауза между перезапусками. |
| `max_backoff` | Максимальная пауза при экспоненциальном откате. |
| `message_limit` | Лимит длины одного исходящего текста при нарезке длинных сообщений. |
| `input_limit` | Лимит длины входящего пользовательского текста. |
| `error_text_limit` | Максимальная длина текста ошибки, отправляемой админу. |
| `send_attempts` | Сколько раз пытаться отправить сообщение. |
| `retry_base_delay` | Базовая задержка между попытками отправки. |
| `greet_cooldown` | Минимальный интервал между подробными стартовыми уведомлениями. |
| `recovery_greet_cooldown` | Минимальный интервал между уведомлениями о восстановлении. |
| `proxy_cache_ttl` | Время жизни кэша прокси. |
| `proxy_fetch_timeout` | Таймаут загрузки списка прокси. |
| `proxy_preflight_timeout` | Таймаут предварительной проверки прокси. |
| `proxy_health_interval` | Интервал проверки подключения. |
| `proxy_health_fails` | Сколько ошибок подряд считать критичными. |
| `telegram_connect_timeout` | Таймаут Telegram-соединения. |
| `telegram_read_timeout` | Таймаут чтения Telegram-соединения. |
| `telegram_pool_timeout` | Таймаут пула соединений. |
| `anonymous_admin_name` | Нейтральное имя анонимного админа чата. |
| `anonymous_admin_username` | Служебный username анонимного админа. |
| `anonymous_admin_user_id` | Служебный Telegram ID анонимного админа. |
| `anonymous_admin_aliases` | Дополнительные имена, которые считаются анонимным админом. |

## Промпт

По умолчанию используется файл:

```text
prompts/GreenTea_v4.txt
```

Если файла нет, бот создаст стандартный промпт автоматически.

В настройках можно указать другой файл:

```toml
[ollama]
prompt = "MyCustomPrompt"
```

Тогда будет использоваться:

```text
prompts/MyCustomPrompt.txt
```

Если нужно полностью отключить системный промпт:

```toml
[ollama]
prompt = ""
```

### Плейсхолдер имени админа

В промпте поддерживается плейсхолдер:

```text
{{ADMIN_NAME}}
```

При загрузке он заменяется на значение:

```toml
[advanced]
anonymous_admin_name = "Админ"
```

Если вы хотите, чтобы анонимный админ назывался `Admin`, поставьте:

```toml
[advanced]
anonymous_admin_name = "Admin"
```

Если в старом конфиге было указано:

```toml
[ollama]
prompt = "Test17"
```

новая версия автоматически переключит его на стандартный новый промпт `GreenTea_v4`.

Если вы хотите использовать другой промпт, укажите его вручную в `settings.toml`.

## Прогрев модели и `keep_alive`

Бот при старте:

1. проверяет доступность Ollama;
2. при необходимости пробует запустить `ollama serve`;
3. отправляет короткий пустой запрос для загрузки модели в память.

За это отвечают:

```toml
[ollama]
keep_alive = "6h"
warmup = true
```

Если прогрев не нужен:

```toml
[ollama]
warmup = false
```

Если модель большая или диск медленный, можно увеличить таймаут прогрева:

```toml
[advanced]
ollama_warmup_timeout = 1800.0
```

## Прокси

Бот умеет работать через прокси.

### Режимы

```toml
[bot]
proxy = ""
```

или

```toml
[bot]
proxy = "auto"
```

Автоматический подбор `socks5`-прокси из источников, указанных в `[advanced]`.

```toml
[bot]
proxy = "direct"
```

или

```toml
[bot]
proxy = "none"
```

Прямое подключение без прокси.

```toml
[bot]
proxy = "socks5://127.0.0.1:1080"
```

Конкретный ручной прокси.

### Как работает авто-режим

- бот загружает список прокси;
- нормализует их в `socks5h://`;
- делает предварительную проверку;
- использует рабочие;
- помечает сломанные;
- при проблемах перезапускается и пробует другой прокси.

## Команды бота

Админ-команды доступны только владельцу бота, указанному в `owner_id`, и только в личных сообщениях.

| Команда | Назначение |
|---|---|
| `/ping` | Проверка живости бота. |
| `/panel` | Админ-панель. |
| `/help` | То же, что `/panel`. |
| `/status` | Состояние бота и текущие параметры. |
| `/history [N]` | Показать последние `N` сообщений истории. По умолчанию 10. |
| `/clear` | Очистить историю целевого чата. |
| `/get` | Показать текущие runtime-параметры генерации. |
| `/set <param> <value>` | Изменить параметр генерации до перезапуска. |
| `/reset` | Сбросить runtime-параметры к значениям из `settings.toml`. |

### Примеры

```text
/status
/history 20
/set temperature 0.2
/set max_tokens 512
/reset
```

Изменения через `/set` действуют только до перезапуска бота.

## Поведение в целевом чате

Бот отвечает только в чате, указанном в:

```toml
[bot]
chat_id = ...
```

### Триггеры ответа

Бот срабатывает в трёх случаях:

1. **Упоминание**  
   Например:

   ```text
   @MyBot как это работает?
   ```

2. **Ответ на сообщение бота**  
   Пользователь нажимает reply на ответ бота.

3. **Случайное срабатывание**  
   Если сработал шанс:

   ```toml
   [bot]
   random_reply_chance = 0.05
   ```

### Если бот занят

Если модель уже обрабатывает запрос:

- на упоминание или ответ бот напишет, что занят;
- случайное срабатывание молча пропускается.

## История

История хранится в памяти процесса.

Особенности:

- после перезапуска история очищается;
- объём ограничен параметром:

```toml
[advanced]
max_history_size = 10
```

- пользовательские сообщения передаются модели в служебном JSON-формате;
- ответы бота хранятся как обычный текст.

## Анонимный админ чата

Если сообщение отправлено анонимным администратором Telegram, бот заменяет его на нейтральное имя.

По умолчанию:

```text
Админ
```

Это имя используется:

- в истории;
- в пользовательском JSON для модели;
- в системном промпте;
- в обращениях в ответах.

Если нужно другое имя:

```toml
[advanced]
anonymous_admin_name = "Admin"
```

Не рекомендуется подставлять туда реальные ники или личные имена.

## Диагностика и частые проблемы

### Бот создаёт `settings.toml` и завершается

Это нормальное поведение первого запуска.  
Заполните обязательные поля и запустите снова.

### Ошибка токена

Проверьте:

```toml
[bot]
token = "..."
```

или файл `key`.

### Бот не отвечает в группе

Проверьте:

- правильный ли `chat_id`;
- правильный ли `username` бота без `@`;
- отключён ли privacy mode;
- добавлен ли бот в группу;
- имеет ли бот нужные права.

### Бот пишет, что занят

Это значит, что модель уже обрабатывает предыдущий запрос.  
На слабом железе генерация может занимать много времени.

### Ошибки Ollama

Проверьте:

```bash
ollama list
```

и:

```bash
ollama run qwen2.5-coder:7b-instruct-q4_K_M "test"
```

Также убедитесь, что сервер доступен:

```text
http://localhost:11434
```

### Прогрев модели не успевает завершиться

Увеличьте:

```toml
[advanced]
ollama_warmup_timeout = 1800.0
```

### Не хватает памяти

Попробуйте уменьшить:

```toml
[generation]
context_window = 4096
max_tokens = 512
```

Или используйте модель меньшего размера / квантования.

## Безопасность

- Не храните токен в публичном репозитории.
- Если используете `key`, добавьте его в `.gitignore`.
- Если храните токен в `settings.toml`, тоже не публикуйте этот файл.
- Админ-команды доступны только `owner_id`.
- Не указывайте реальные личные имена в `anonymous_admin_name`.

Пример `.gitignore`:

```gitignore
key
settings.toml
logs/
__pycache__/
```

Если вы хотите оставить шаблон настроек в репозитории, лучше хранить отдельный `settings.example.toml` без секретов.

## Назначение бота

Этот бот задуман как:

- локальный инженерный ассистент;
- компактный инструмент для коротких технических ответов;
- стабильный монолит без внешних баз данных;
- решение для работы на слабом железе;
- бот с сухим, точным и слегка циничным стилем ответов.

Он не рассчитан на:

- облачные интеграции;
- активный интернет-серфинг;
- работу с внешними файлами пользователя без явной реализации;
- длинные многостраничные ответы без необходимости.
